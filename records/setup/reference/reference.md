## game

Stack

## presentation game

Royal Match

## reason

The request names Stack by Ketchapp ("like Stack by Ketchapp"): the same one-tap block stacking loop with cut-off overhangs, perfect drops and an instant restart. Its screens have almost no UI, so Royal Match (Dream Games), a casual mobile game with highly finished lobby, HUD, popups and result screens, is the presentation game. Both videos were recorded on mobile (Android/iOS). YouTube URLs: `XtkBkit39sA.mp4` https://www.youtube.com/watch?v=XtkBkit39sA (Stack gameplay), `Es7E14DUbo4.mp4` https://www.youtube.com/watch?v=Es7E14DUbo4 (Royal Match gameplay walkthrough part 1).
